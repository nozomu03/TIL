# Unreal 라이브 세션
- TObjectPtr
  - UE4에서 사용하는 UObject* 원시 포인터를 대체
    - 스마트 포인터
    - 개발 과정에서만 쓰이고 컴파일 후에는 원시 포인터로 전사
    - 지연로딩 
    - 엑스 트래킹
    - 사용시에는 &(Reference) 활용
      - 값 복사 예방

- TSubClassOf
  - UPROPERTY(EditAnyWhere) 시 범우 한정
    - ex) UActorComponent와 그 자식 클래스만 뜨게 하기

- TArray
  - 연속 메모리
  - 순차 순회(및 접근) 빠름
    - O(1)
  - 삽입 / 검색 / 삭제 느림
    - O(n)    
  - 캐시 친화적  
  - 멤버함수
    - 삽입
      - Add()
        - Emplace()에 비해 느리지만 명확함
      - Emplace()
        - 효율적이지만 암시적 변환 가능성 有
      - AddUnique()
        - 유일값 체크
        - 성능 低 
          - TSet 사용
      - Insert()
        - 특정 인덱스에 값 삽입
    - 삭제
      - Remove()
        - 해당 값 전부 삭제
      - RemoveSingle()
        - 해당 값이 처음으로 발견된 인덱스 삭제
      - RemoveAt()
        - 특정 인덱스 삭제
        - IsValidIndex() 체크 권장
      - RemoveAll()
        - 매개변수로 함수 객체
        - 조건에 해당하는 값 전부 삭제
    - Num()
      - 인덱스 개수 반환
      - 단독 사용 불가 
        - if, for 등에서 체크 용으로 사용
    - FilterByPredicate()
      - 매개변수로 함수 객체
      - 함수객체를 조건으로 필터링된 값들 반환(TArray)
    - 검색
      - Find()
        - 인덱스 번호(int) 반환
      - Contain()
        - 포함 여부(bool) 반환


- TSet / TMap
  - 해시 분산
  - 접근 / 검색 / 삽입 / 삭제 빠름
    - O(1)
  - TSet
    - 순회 방법
      
          for (TSet<int32>::TIterator it = IntSet.CreateIterator(); it; ++it){
              // 수정 가능
          }

          for (TSet<int32>::TConstIterator it = IntSet.CreateConstIterator(); it; ++it)
          {
              // 수정 불가
          }
    - Compact();
      - 빈 메모리 공간을 맨 뒤로 뻄
    - Shrink();
      - 빈 메모리 공간 삭제
    - Array()
      - TSet을 TArray로 변환
  - TMap
    - Key: Value
    - FindOrAdd()
      - 검색해서 못찾으면 생성
        - 참조자 반환
