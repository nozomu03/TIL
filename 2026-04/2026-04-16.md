# Unreal
## GameMode 클래스
- GameModeBase
  - 단순화된 클래스
  - 멀티플레이용 로직 x
- GameMode
  - GameModeBase의 자식
  - 다양한 기능 포함

- 적용법
  1. Project Setting - Project - Maps & Modes - Default Game Mode
    - 프로젝트 내 모든 레벨이 일괄 적용
  2. Window - World Setting - Game Mode - GameMode Override
    - 현재 레벨에만 적용
  - GameMode Override 옵션이 우선됨

## 사용자 입력
- Input Mapping Context  
  - 각 Action에 키 바인딩
  - Action 별 모디파이어 지정
    - Swizzle Input Axis Value
      - 입력값의 xyz 축을 변경
      - xyz to yxz 등
    - Negate  
      - 입력값 부정       
- Input Action
  - 해당하는 액션이 어떤 종류의 값을 가지는지 정의
    - bool, float, Vector2D, Vector  
- 플레이어 캐릭터에 IMC 등록하는 법

        ASpartaPlayerController::ASpartaPlayerController() : MoveAction(nullptr), JumpAction(nullptr), SprintAction(nullptr), LookAction(nullptr)
        {
        }

        void ASpartaPlayerController::BeginPlay()
        {
            Super::BeginPlay();
            if (ULocalPlayer* LocalPlayer = GetLocalPlayer())
            {
                if (UEnhancedInputLocalPlayerSubsystem* EnhancedInputSubsystem = LocalPlayer->GetSubsystem<UEnhancedInputLocalPlayerSubsystem>())
                {
                    if (InputMappingContext)
                    {
                        EnhancedInputSubsystem->AddMappingContext(InputMappingContext, 0);
                    }
                }
            }
        }
