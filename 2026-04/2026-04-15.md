# Unreal
## 헤더파일 분석
1. CoreMinimal.h
   - 언리얼 엔진에서 지원하는 자료형, 함수 등을 선언해둔 헤더
2. GameFramwork/Actor.h
   - Actor 클래스의 구성요소들을 선언해둔 헤더
3. Item.generated.h
   - 리플렉션 시스템이 생성해주는 헤더

## 명명규칙
1. A(액터 및 액터를 상속받은 클래스)
2. U(오브젝트)
3. F(구조체)
4. E(Enum)

## 컴포넌트
- 보통 Scene 컴포넌트를 루트 컴포넌트로 사용
- 원하는 에셋 우클릭 - Copy Reference로 경로 복사 가능
- ConstructorHelpers::FObjectFinder 로 에셋 경로를 지정할 땐 /로 시작
       
        ex) "/Game/Resources/Props/SM_Chair.SM_Chair"

    - /로 시작하지 않을 경우 경로 인식 불가
  
## 라이프사이클
1. BeginPlay()
   - 액터 Spawn 직후
2. Tick(float DeltaTime)
   - 매 틱마다 호출
   - PrimaryActorTick.bCanEverTick = true 없을 시 작동 안함
   - DeltaTime
     - Tick과 Tick 사이 흐른 시간

3. PostInitializeCompnents()
    - 컴포넌트 초기화 완료 후 호출
4. Destroyed()
    - 액터 삭제 직전
5. EndPlay()
    - 게임 종료 시 / 액터 삭제 시 / 레벨 전환 시 
- 생성자 -> PostInitializeCompnents -> BeginPlay -> (Destroyed) -> EndPlay
- 생성자와 Destroyed는 에디터에서 액터 배치 / 삭제 시에도 호출

## 리플렉션
1. UCLASS()
   -  Blueprintable
      -  블루프린트 생성 가능
   -  NotBlueprintable
      -  블루프린트 생성 불가능
   -  Abstract
      -  추상 클래스
      -  레벨에 직접 배치 불가
2. UPROPERTY()
    - VisibleAnywhere
      - 인스펙터 창에 표시
    - EditAnywhere
      - 인스펙터 창에 표시 + 수정 가능
    - Category
      - 인스펙터에 해당 프로퍼티가 출력될 카테고리 지정
    - BlueprintReadOnly
      - 블루프린트 그래프에 표시
    - BlueprintReadWrite
      - 블루프린트 그래프에 표시 + 수정 가능
