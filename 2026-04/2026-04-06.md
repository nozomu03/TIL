# Unreal 엔진

## 솔루션 구조
1. Engine
   - 언리얼 엔진 소스코드
2. Games
   - 게임 소스 코드
3. Programs
   - 기타 툴
4. Rules
   - 프로젝트 빌드 규칙 정의 폴더
5. Visualizers
   - 디버깅용 설정 파일 폴더

## 빌드 설정
1. DebugGame (Editor)
    - 게임 로직 디버깅
    - 별도 실행 파일 생성
    - Editor는 에디터를 통한 디버깅 
2. Development (Editor)
    - 일반적으로 많이 쓰임
    - DebugGame에 비해 디버그 정보 적음
    - 보다 최적화되어 있음
    - 에디터 없이 실행파일 형태
    - Editor 는 에디터 이용

3. Shipping
   - 출시용 빌드
   - 가장 최적화 되어 있음

- 빌드 시에는 언리얼 엔진 종료 권장

## 전체 빌드 VS 부분 빌드
||전체 빌드|부분 빌드|
|:--:|:--:|:--:|
|포함 내용|엔진 코드 포함|게임 프로젝트 코드만|
|속도|느림|빠름|
|사용하는 경우|첫 빌드 / 엔진 로직 수정 시|C++ 로직 수정 시|

## Migrate
- A 프로젝트의 콘텐츠를 B 프로젝트로 옮겨주는 기능
- 복사가 아닌 이동
- 원본 프로젝트에선 폴더 구조만 남고 Migrate 대상이 된 파일들이 사라짐
