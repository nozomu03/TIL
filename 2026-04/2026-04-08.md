# 알고리즘
## Map
1. 유일값 key와 key와 연결된 value로 구성
   - [ ] 사용 시 이미 존재하는 key를 다시 삽입하면 덮어씌움
   - insert({pair}) 사용 시 이미 있는 값은 건너뜀
2. key 기준으로 정렬
3. O(log n)으로 효율적인 검색/삽입/삭제
    - 내부적으로 이진 탐색 트리 사용
4. 없는 키를 검색할 시 자동 생성됨
   - 카운팅에 자주 활용

## Set
1. value 없이 key 로만 구성
2. 중복 비허용
3. 자동 정렬

## unodrered_map
1. 해시 테이블을 사용하는 map
2. 정렬 x
3. 평균 검색 속도 O(1)
