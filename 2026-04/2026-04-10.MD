# Unreal
## Reflection
- 런타임 상에서 프로그램이 자신의 구조를 확인하고 조작하는 것.
- UBT -> UHT -> 컴파일 -> 완료
  
## 가비지 콜렉터(GC)
- 메모리 관리 도구
- 사용되지 않는 메모리 반환 -> 메모리 누수와 댕글링 포인터 문제 예방
- 언리얼 엔진은 표준 C++과 달리 가비지 콜렉터 존재
- 리플렉션(UPROPERTY 매크로)을 통해 포인터 추적
- Project Setting - Engine - Garbage Collection에서 설정 가능
- UPORPERTY()를 사용하지 않을 경우 사용 중인 포인터를 삭제할 가능성 有
  - IsValid / != nullptr 로 예외 처리 불가(무조건 ture)
  - IsValidLowLevel(), TWeakObjectPtr<> 사용

## UBT(Unreal Build Tool)
- 사용 모듈, 현재 플랫폼 등 체크
- 프로젝트 구조 체크

## UHT(Unreal Header Tool)
- 매크로 메타데이터 수집
- 에디터 디테일 창 연동
- 블루프린트 노드 연결 정보 준비
- generated.h 생성
- 라이브 코딩이 제대로 작동하지 않는 경우는 대부분 UHT 문제
  - 헤더 파일 변경 시 리빌드가 필요한 이유

## CDO(Class Default Object)
- UObject 클래스의 기본값을 보관하는 오브젝트
- 모듈 로딩 시(엔진이 켜진 이후) 생성
  - 생성자는 딱 한 번만 호출됨
  - 멤버변수를 생성자에서 초기화하는 것을 권장하는 이유
- 장점
  1. 메모리 절약
  2. 초기화 속도 향상
  3. 델타 직렬
- CDO는 임의 수정 엄금
