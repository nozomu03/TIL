# C / C++
  - 스택 메모리
    - 함수의 호출 비용 최소화
    - main -> main 호출 함수 -> 가 호출한 함수 ㆍㆍㆍ
    - LIFO(Last In First Out)
  - 스택 프레임
    - 특정 함수를 위해 확보된 메모리 공간
    - 시작주소(EBP)
    - Top 주소(ESP)
  - 스코프
    - 선언된 변수/함수를 사용할 수 있는 공간(범위)
    - 블록 스코프
      - 특정 중괄호 내에서 선언된 변수
      - 지역변수
    - 파일 스코프
      - 해당 소스 코드 파일 최상단(#include, #define 등 밑에) 선언된 변수/함수
      - 전역변수/전역함수
    - static 키워드
      - 변수를 정적 변수로 선언
      - 스택 메모리 x 데이터 섹션에 저장 
      - 프로그램 종료 시까지 유지
      - 함수 종료 후에도 사라지지 않음 -> 추후 같은 함수 다시 호출 시 값 유지
      - 전역에서 사용할 시 해당 파일 스코프에서만 접근 가능
    - const 키워드
      - 상수변수 키워드
      - 선언 시점 이후 값 변경 불가
  - 전방 선언 
    - main 함수에서는 컴파일 시점에서 이미 선언된 함수만 호출 가능
    - 소스코드는 위에서 아래로 순차적으로 컴파일
    - main 상단에 함수를 미리 선언(ex. int Add();) 
    - 함수 정의를 main보다 나중에 해도 문제 없이 사용 가능
  - 포인터
    - 메모리 주소를 값으로 가지는 변수
    - (자료형)* 형태
      - 역참조 시 몇 Byte 읽을 지 알려면 자료형 필요
    - 다른 변수의 주소를 가질 수 있음(int a = 10; int* b = &a)
      - &(엠퍼샌드)
        - 해당 변수의 메모리 주소값    
        - 단, 배열 변수는 & 없이 변수명으로 할당(int a[50]; int* b = a)
  - 역참조 연산자
    - *(애스터리크)
    - 포인터 변수에 붙어 해당 주소에 저장된 값을 가져옴.
      - int a = 20; 
      - int* b = &a; 
      - printf("%d", *b); 
      - -> 20  
    - 역참조 연산자를 붙인 포인터 변수의 값을 수정하면 원본 변수도 수정됨
      - int a = 20; 
      - int * b = &a; 
      - *b = 30; 
      - printf("%d", a) 
      - -> 30
    - 만약, 포인터에 할당된 값이 배열의 주소일 경우(int a[50]; int* b = a)
      - *b는 a[0]의 값(b는 a[0] 주소값)
      - a[n]의 값은 *(b+n) (a[n]의 주소값은 (b+n))
      - (포인터 변수) + 1은 해당 자료형의 다음 요소의 메모리 주소값으로 이동(내부적으론 저장된 주소값에 해당 변수 자료형의 sizeof() 값만큼 이동)
      - ∴ *(포인터 변수 + 1)은 다음 인덱스에 저장된 값
  - 포인터의 초기화
    - 선언과 동시에 할당하는 경우가 아니면 null 사용
