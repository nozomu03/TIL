# Unreal
- 레벨 디자인
  - 레벨은 플레이어가 탐험하고 상호작용하는 공간
  - 유저에게 제공할 경험을 설계하는 일 
- Migrate
  - 폴더 우클릭 - 마이그레이트
  - 다른 플로젝트로 폴더 내용 복제

- 이벤트
  - Begin Play
    - 시작시 한 번만(Unity - Start)
  - Tick
    - 매 틱마다 한 번씩(Unity - Update)

- Character
  - Character Movement 컴포넌트가 적용되어 있는 액터.
  - Possess를 통한 유저의 직접 제어
  - Input Mapping Context
    - 입력 장치의 입력을 받아 특정 행동을 수행하도록 함
  - Input Action
    - Input Manager Context에 연결
    - 해당 입력이 가진 값의 종류를 정의
  - 언리얼에서 카메라 회전은 Roll / Pitch / Yaw
  - 점프 구현은 Jump 노드
  - Oriental Rotation to Movement
    - 이동 방향에 따라 캐릭터 회전

- Actor Blueprint
  - Instance Editable
    - 해당 옵션이 체크된 변수는 레벨에 배치 시 General - Default 에서 수정 가능
    - 같은 Actor Blueprint를 공유해도 오브젝트마다 별도의 값
  - Blueprint 실행을 잠시 멈추고 싶을 때 Delay 노드

# C / C++
- 이중 반복문
  - 보통 for문 사용
  - 첫 번째 for의 인덱스가 i, 2번째가 j 일 때, jxi 회 실행
- 배열
  - 같은 타입의 변수 여러개를 묶어 놓은 것.
  - 고정 크기
  - n개의 원소
  - 2차원 배열
    - n x m 개의 원소
- 함수
  - 특정 기능을 수행하주는 코드 뭉치
  - 재사용성
  - 반환 자료형
  - 반환값
  - 매개변수
