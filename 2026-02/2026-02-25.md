# Unreal
- 블루프린트
  - 언리얼 엔진의 비주얼 스크립팅 툴

- 레벨 블루프린트
  - 이벤트 함수
    - 특정 사건이 발생하면 호출되는 함수
      - Begin Play: 게임 플레이 시작 시
      - Tick: 매 프레임마다
  - PlayStinrg(): 문자열 출력
  - 블루프린트 수정 후에는 컴파일 버튼 클릭
- 변수
  - 상수(값)을 저장할 수 있는 그릇
  - 멤버 변수는 보통 프로퍼티(Property)라 호칭
  - 명명 규칙
    - 대문자로 시작
    - boolean은 소문자 b로 시작
  - Boolean: 논리값
  - Byte: 정수(255)
  - Integer: 정수(-21억 ~ 21억)
  - Intger64: 정수(가장 큼)
  - Float: 실수
  - Name: 불변문자열
  - String: 가변문자열
  - Text: 문자열(다국어)
- 변수 값 사용
  - 변수를 이벤트 그래프에 드래그 앤 드롭(Get/Set 선택)
- 연산 노드
  - 연산 노드 검색 시 이름 말고 기호로도 검색 가능(ex) +, - 등) 
  - 사칙연산, 비교연산, 논리연산(XOR 포함)
- 흐름 제어
  - Branch(if-else)
  - Sequence
    - 순서대로 실행
    - 노드가 많을 때 사용하면 가독성 유리
  - 사용자 입력
    - Pressed / Released
    - 마우스는 좌/우 노드 따로
    - 키보드는 각 키 마다 노드 따로
  - 함수
    - 비슷한 역할을 하는 코드를 하나로 묶어줌(코드의 재사용)
    - 함수명은 보통 동사로 시작
  - 반복문
    - while
      - condition의 참/거짓으로 반복 여부 판단
    - for
      - First Index / Last Index
  - ForEach
    - Array 값 순회
    - Array Index와 해당 Index의 값 사용 가능
    - Array
      - 같은 자료형의 변수 여러 개를 하나의 변수에 담는 변수
  - Switch
    - Switch On Enum 자료형 으로 검색
    - Enum의 상태에 따라 분기
    - Enumeration
      - 복수 개의 상수를 차례로 저장해둔 열거형
      - Blueprint - Enumeration로 추가
  - 구조체
    - 개발자가 직접 정의한 자료형
    - 하나의 구조체 안에 여러 개의 변수 포함 가능
    - Blueprint - Structure로 추가
    - 내부 속성값 접근 위해서는 Break 노드 필요
    - 값 수정 시에는 Make 노드 필요

# C / C++
- 조건문
  - if: 참일 때
  - if-else 참일 때 / 그 외 모든 경우
  - if-else if-else / 조건 1 참일 때 / 조건 2 참일 때 / 그 외 모든 경우
  - switch-case-default
    ###
        switch(사용 변수)
        {
            case 값1:
              명령
              break;
            case 값2:
              명령
              break;
            default:
              명령
              break;
        }
    - break 안 쓰면 아래 case까지 전부 실행(International-Fallthrough)
    - case에 중괄호로 변수 선언 가능
  
- 반복문
  - while    
  - for
  - do-while
    - 최초 1회 반복 보장
  - 무한루프
    - for(;;) / while(1)
  - break: 루프 완전 탈출
  - continue: 이번 루프만 스킵(재실행)
