## C / C++ 
- 진법에 관하여
    - 각각의 진법은 0부터 n-1까지의 숫자(+문자)로 이루어짐
    - 9를 넘어가는 숫자는 알파벳으로 표현(A<sub>16</sub> = 10<sub>10</sub>)
    - n진법을 10진법으로 변환하는 법
        ### ∑ (ㅁ<sub>i</sub> x a<sup>i</sup>) (단, i는 자릿수 순서의 오름차순, a는 해당 순서의 자릿수)
        ### ex) 1011<sub>2</sub> 
        ### 1 x 2<sup>3</sup> + 0 x 2<sup>2</sup> + 1 x 2<sup>1</sup> + 1 x 2<sup>0</sup> = 11<sub>10</sub>

    - 10진법 숫자 N을 n진법으로 변환하는 법
        ### 몫이 0이 될 때까지 N을 n으로 계속 나누어 나머지 값을 역순으로 읽은 값
        ### 
        ### ex) 24<sub>10</sub>
        ### 24 mod 2 = 0 | 24 / 2 = 12
        ### 12 mod 2 = 0 | 12 / 2 = 6
        ### 6 mod 2 = 0 | 6 / 2 = 3
        ### 3 mod 2 = 1 | 3 / 2 = 1    
        ### 1 mod 2 = 1 | 1 / 2 = 0
        ### ∴ 24<sub>10</sub> = 11000<sub>2</sub>

- 문자의 경우에 관하여
  - C에서 문자는 기본적으로 정수값으로 변환되어 저장
    - 대부분 ASCII 체계 사용
  - 하나의 문자는 고유의 정수값을 가짐.
  - char 변수에 문자를 저장할 시 메모리에는 해당하는 정수값 저장
  - 서식 지정자 %d로 문자와 정수 연산 시 (코드값) + 정수 꼴로 출력
    - printf("%d", 'A' + 1) // 66
  - 서식 지정자 %c로 문자와 정수 연산 시 ((코드값) + 정수)를 ASCII 코드값으로 가진 문자 출력
    - printf("%c", 'A' + 1) // B
  - ASCII는 알파벳, 숫자, 몇가지 특수문자만 표현할 수 있음
  - EUC-KR과 같은 각 국가마다 고유의 체계를 사용
  - 유니코드를 통해 대부분의 언어를 지원하도록 발전

- 연산자와 피연산자
  - 연산자(Operator)
    - 특정 식을 계산할 때 연산 방식을 지정하는 기호
    - ex) +, - , *, /
  - 피연산자(Operand)
    - 연산자의 적용 대상이 되는 값 또는 식
    - ex) 숫자, 문자, 변수 등
  - 연산자의 우선순위
    - 여러 연산자가 있을 떄 어떤 연산을 먼저 수행할지 정하는 규칙
    - 괄호를 통해 순서를(괄호 안이 우선) 변경할 수 있음
    - 산술연산자(+, -, *, /)의 경우 *, / 가 +, - 보다 우선
  - 나머지 연산자(모듈러 연산자)
    - % 기호 사용
    - a % b 의 꼴을 띄며 a를 b로 나누었을 때의 나머지를 의미
    - a와 b는 정수여야 함
  - 같은 자료형 간 연산 시 결과값도 동일한 자료형을 유지
    - 정수와 정수 간의 나눗셈의 경우 소수부는 버려짐
  - 복합 연산자
    - 연산을 수행함과 동시에 자기 자신에게 대입
      - (연산자)= 의 형태를 가짐
      - ex) a (연산자)= b -> a = a (연산자) b 
- 증감 연산자
  - 피연산자의 값을 1 늘리거나 줄이는 연산자
  - 전치: 피연산자 앞에 사용하며 먼저 증감 후 값 사용
    - ex) ++num
  - 후치: 피연산자 뒤에 사용하며 기존 값 사용 후 증감
    - ex) num++
- 논리 연산자
  - C에서 0 이외 모든 값(음수 포함)은 참
  - 0으로 취급되는 값
    - NULL
    - '\0'
  - 논리 회로의 그것과 동일
    |구분|논리곱|논리합|부정|
    |:-:|:-:|:-:|:-:|
    |C|&&|\|\||!|
    |논리 회로|∧|∨|'|
  - 논리곱에서 a && b 일 때, a == false면 b와 비교 x
  - 논리합에서 a || b 일 때, a == true 면 b와 비교 x
- 관계 연산자
  - 이상(a >= b) | 이하(a <= b)  
  - 초과(a > b) | 미만(a < b)
  - 동일(a == b)
  - 다름(a != b)
  - 단, a < b < c 와 같은 연속 비교 불가
    - a < b < c는 (a < b) < c 로 해석
    - a < b && b < c 형태로 표현
- 형변환 연산자
  - (자료형) 형태
  - 피연산자를 해당 자료형으로 변환해줌
    - ex) a=123; float b =(float)a;
    - 정수끼리의 나눗셈 연산 시 (float) 사용 -> 소숫점 출력
      - 5 / 2 -> 2
      - (float)5 / 2 -> 2.5
- 삼항 연산자
  - (조건식) ? (참일 때 값) : (거짓일 때 값) 형태
  - ex) a > b ? 0 : 1
- sizeof 함수
  - 해당 자료형의 크기(byte) 반환
    - ex) sizeof(int) -> 4
