# C++
## 메모리 관리
- 스택 메모리
  - 스택 메모리에 저장된 변수의 생존주기가 끝났을 때 메모리 자동 반환
- 힙 메모리
  - 동적 할당
  - 수동 반납
    - 반납 시까지 유지 가능
    - 메모리 누수 위험 多
  - new(할당)
  - delete(반납)
  - 배열 선언 시 크기를 변수로 관리 가능

        int size;
        cin >> size;
        int* arr = new int[size];
        //...
        delete[] arr;

  - Dangling Pointer
    - 포인터는 자신이 가리키고 있는 메모리에 변수가 할당되어있는지 반납되었는지 알지 못함
    - 이미 반납된 메모리를 가리키는 포인터
    - 같은 주소를 가리키는 포인터를 2개 이상 쓰면 발생 가능

            int* p1 = new int(10);
            int* p2 = p1;
            delete p1;
            cout << *p2 << endl;

  - 메모리 누수
    - 접근할 수 없으면서, 반납되지도 않은 메모리
    - 결과적으로 메모리 기아 유발
    - 사용 종료된 변수를 해제하지 않을 경우 발생할 수 있음
  - 스마트 포인터
    - delete 없이 목적에 맞는 전용 포인터 생성
    - unique_ptr
      - 오로지 하나의 포인터만 소유권을 가질 수 있음
      - move() 함수로 소유 포인터 변경 가능
    - shared_ptr
      - 레퍼런스 카운트를 통해 소유권 공유
      - 레퍼런스 카운트가 0이 되면 반납
      - use_count()로 래퍼런스 카운트 값 확인
      - reset()으로 다른 객체를 소유하거나 소유한 객체를 해제
    - weak_ptr
      - 래퍼런스 카운트 증감 없이 참조(약한 참조)
      - 순환 참조 회피            
      - lock() 메소드로 유효한 포인터인지 확인하고 사용해야함
  - 복사
    - 얕은 복사
      - 같은 메모리 공간을 참조
      - 원본 값을 수정 시 같이 변함
      - 원본 delete 시 Dangling Pointer 발생
      
            int* p1 = new int(1);
            int* p2 = p1;

    - 깊은 복사
      - 원본 포인터가 가리키는 값을 다른 메모리 영역에 복제해서 생성
      - 원본 값을 수정해도 값이 변하지 않음
      - 원본 delete 해도 Dangling Pointer x
            
            int *p1 = new int(1);
            int *p2 = new int(*p1);

- 숙제 1

        #include <iostream>
        using namespace std;

        class MyClass {
            private:
                int* ptr;

            public:
                // 생성자
                MyClass() {
                    ptr = new int(10); // 동적 메모리 할당
                    cout << "메모리 할당 완료!" << endl;
                }

                // 소멸자
                ~MyClass() {
                    delete ptr;
                    // 소멸자에서 ptr 반납
                }

                void print() const {
                    cout << "값: " << *ptr << endl;
                }
        };
        int main() {
            MyClass obj;
            obj.print();

            // main 함수 종료
            return 0;
        }

- 숙제 2

        #include <iostream>
        using namespace std;

        class Logger {

        private:
            int log_count = 0;


        public:    
            Logger() = default;

            ~Logger() {

            }

            void LogInfo(std::string message) {
                std::cout << "[Info] " << message << std::endl;
                this->log_count++;
            }

            void LogWarning(std::string message) {
                std::cout << "[Warning] " << message << std::endl;
                this->log_count++;
            }

            void LogError(std::string message) {
                this->log_count++;
                std::cout << "[Error] " << message << std::endl;
            }

            void ShowTotalLogs() {
                std::cout << this->log_count << std::endl;
            }

        };

        int main() {
            unique_ptr<Logger> logger = make_unique<Logger>();
            logger->LogInfo("Info Message");
            logger->LogWarning("Warning Message");
            logger->LogError("Error Message");

            logger->ShowTotalLogs();
            // main 함수 종료
            return 0;
        }
