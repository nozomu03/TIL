1. Stack
   - LIFO(Last In First Out)   
   - 임의 접근 불가
   - push(x)     
     - 값 삽입
     - - O(1)
   - pop()   
     - 제일 나중에 삽입된 값 삭제
     - O(1)
   - top()
     - pop() + 값 반환
     - O(1)
   - 주로 실행취소 / DFS에서 사용
2. Queue
   - FIFO(First In First Out)
   - push(x)
   - pop()
   - front()
   - back()
   - 주로 대기열이나 BFS에서 사용

3. deque
    - 맨 앞 / 맨 뒤에서 삽입 삭제가 O(1)인 자료구조
    - Queue와 Stack은 deque의 접근 방식을 제한해서 구현
