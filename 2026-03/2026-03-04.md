# 알고리즘 기초
- 알고리즘
  - 문제를 해결하기 위한 절차, 방법
- 시간 복잡도
  - n이 커질 때 연산 횟수가 얼마나 늘어나는가(단, n은 입력 데이터의 크기)
    |표기|의미|예시|
    |:-:|:-:|:-:|
    |O(1)|상수|해시 탐색|
    |O(n)|선형|순차 탐색|
    |O(n<sup>2</sup>)|이차|버블 정렬|
    |O(log n)|로그|이진 탐색|

  - 속도 차이<br>상수 < 로그 < 선형 < 이차

# C++
## iostream
- 입출력 관련 기능 헤더 파일<br>(C++은 헤더파일에 .h 안 붙임)  
- 형식 지정자 x
- cin
  - 콘솔 입력  
- cout
  - 콘솔 출력
- endl
  - 개행(≒ "\n")

### 예시
    #include <iostream>    
    int main(void) {
        int a;
        std::cin >> a; // 정수 입력
        std::cout << a << std::endl; // 정수 출력, 개행
    }

## namespace
- 여러 함수와 변수, 클래스 등등을 하나의 포장으로 묶은 것
- std는 string와 같은 여러 클래스와 cin, cout을 비롯한 여러 함수를 포함
- [네임스페이스명]::[속성명] 의 형태로 내부 속성 접근
- using namespace [네임스페이스명]을 통해 속성에 바로 접근 가능
  - 이름 충돌 가능성 있음(모호함)
  - using [네임스페이스명]::[속성명] 형태로 특정 속성만 뽑아서 사용 추천

### 사칙연산기 코드
    #include <iostream>
    int main(void) {
	int num1 = 0;
    int num2 = 0;
	char ope = '+';

	std::cout << "연산할 값 입력" << std::endl;
	std::cin >> num1;
	std::cout << "연산될 값 입력" << std::endl;
	std::cin >> num2;
	std::cout << "연산자 입력" << std::endl;
	std::cin >> ope;

	switch (ope) {
		case '+' :
			std::cout << num1 + num2 << std::endl;
			break;
		case '-':
			std::cout << num1 - num2 << std::endl;
			break;
		case '*':
			std::cout << num1 + num2 << std::endl;
			break;
		case '/':
			if (num2 == 0) {
				std::cout << "0으로 나눌 수 없음" << std::endl;
				break;
			}
			std::cout << num1 / num2 << std::endl;
			break;		
	    }	
    }
