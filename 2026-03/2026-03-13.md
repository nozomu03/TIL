# C++ 
## 객체지향적 설계란?
1. 재사용성이 좋음
2. 응집도가 높음
3. 결합도가 낮음
4. SOLID 원칙을 준수함

## 응집도
- 하나의 클래스 안에서 멤버들 간의 관련성을 나타내는 척도
- 기능적(High) - 순차적 - 통신적 - 절차적 - 시간적 - 논리적 - 우연적(Low)
- 높을수록 멤버들끼리 관련성이 높다는 의미
- 기술적
  - 단일 목적을 위해 만들어진 멤버들
- 순차적
  - A의 출력이 B의 입력 B의 출력이 C의 입력 ㆍㆍㆍ
- 통신적
  - 서로 동일한 입출력 사용
- 절차적
  - A 실행 - A 종료 - B 실행 - B 종료 ㆍㆍㆍ
- 시간적 
  - 특정 상황에서 동시에 실행되는 것들끼리 묶여있음
- 논리적
  - 비슷한 기능들끼리 묶여있음
- 우연적
  - 관련 없음

## 결합도
- 2개 이상의 클래스 간의 관계에서 서로가 서로에게 얼마나 의존하고 있는지 나타내는 척도
- 내부(High) - 공통 - 외부 - 제어 - 스탬프 - 자료(Low)
- 낮을수록 다른 클래스에 의존하지 않는다는 의미
- 내부
  - 다른 클래스의 멤버를 직접 참조 / 수정
- 공통
  - 공통되는 전역변수 공유
- 외부
  - 외부에 선언된 데이터(파일, 장치 등)를 여러 클래스에서 돌려씀
- 제어
  - 다른 클래스의 멤버를 제어하기 위한 신호 사용
- 스탬프
  - 다른 클래스와 데이터 전체 전송 / 수신
- 자료
  - 다른 클래스로 필요한 데이터만 매개변수로 전달 / 수신

## SOLID
### S
- 단일책임 원칙(Single Responsibility Principle)
- 하나의 클래스는 하나의 역할만 해야 함
- 여러 역할을 수행하는 클래스는 분할하기

### O
- 개방 폐쇄 원칙(Open-Closed Principle)
- 클래스는 확장될 수 있으나 수정되어선 안 됨
- 하나의 부모 클래스를 상속받은 여러 자식 클래스의 형태로 클래스의 직접 수정 회피

### L
- 리스코프 치환 원칙(Liskov Substitution Principle)
- 부모 클래스를 자식 클래스가 대체되어도 기능 오류가 발생해선 안 됨
- 자식 클래스는 부모의 모든 기능을 일관성 있게 유지해야 함

### I
- 인터페이스 분리 원칙(Interface Segregation Principle)
- 클래스는 의미 없는 멤버를 함수를 가져선 안 됨

### D
- 의존 역전 원칙(Dependency Inversion Principle)
- 부모 클래스에서 자식 클래스를 직접 포함하는 것이 아닌 인터페이스를 통해 포함해야 함

    #include <iostream>
    #include <vector>
    #include <string>

    using namespace std;

    class Task {
    private:
        string description;
        bool completed;
    public:
        Task(const string& desription) : description(desription), completed(false) {}
        ~Task() {}

        void complete() {
            this->completed = true;
        }
        
        string getDescription() const{
            return this->description;
        }

        bool isCompleted() const{
            return this->completed;
        }   
    };

    class IStorage {
    public:
        virtual void addTask(Task task) = 0;
        virtual vector<Task> getTasks() = 0;
        virtual string getStorageType() = 0;
        virtual ~IStorage() {}
    };

    class MemoryStorage : public IStorage{
    private:
        vector<Task> tasks;

    public:
        void addTask(Task task) override {
            this->tasks.push_back(task);
        }
        
        vector<Task> getTasks() override {
            return this->tasks;
        }

        string getStorageType() override {
            return "메모리 저장소";
        }

    };

    class DBStorage : public IStorage {
    private:
        vector<Task> tasks;

    public:
        void addTask(Task task) override {
            cout << "DB에서 할 일 추가: " << task.getDescription() << endl;;
            this->tasks.push_back(task);
        }

        vector<Task> getTasks() override {
            cout << "DB에서 할 일 가져오기" << endl;
            return this->tasks;
        }

        string getStorageType() override {
            return "DB 저장소";
        }

    };

    class TaskManager {
        IStorage* storage;

    public:
        TaskManager(IStorage* s) : storage(s) {}

        // 새로운 할 일 추가
        void addTask(const string& description) {
            storage->addTask(Task(description));
        }

        // 현재 할 일 목록 출력
        void showTasks() {
            cout << "저장 방식: " << storage->getStorageType() << "\n";
            vector<Task> tasks = storage->getTasks();
            for (size_t i = 0; i < tasks.size(); ++i) {
                cout << i + 1 << ". " << tasks[i].getDescription();
                if (tasks[i].isCompleted()) cout << " [완료]";
                cout << "\n";
            }
        }

        // 특정 할 일을 완료 처리
        void completeTask(size_t index) {
            vector<Task> tasks = storage->getTasks();
            if (index > 0 && index <= tasks.size()) {
                tasks[index - 1].complete();
                storage->addTask(tasks[index - 1]); // 변경된 할 일 저장
            }
            else {
                cout << "잘못된 번호입니다.\n";
            }
        }
    };



    // 메인 함수
    int main() {
        cout << "=== MemoryStorage로 작업 ===\n";
        MemoryStorage memoryStorage;
        TaskManager manager1(&memoryStorage);

        manager1.addTask("C++ 과제 작성하기");
        manager1.addTask("SOLID 원칙 공부하기");

        cout << "\n현재 할 일 목록:\n";
        manager1.showTasks();

        manager1.completeTask(1);

        cout << "\n업데이트된 할 일 목록:\n";
        manager1.showTasks();

        cout << "\n=== DBStorage로 작업 ===\n";
        DBStorage dbStorage;
        TaskManager manager2(&dbStorage);

        manager2.addTask("DB 작업 테스트");
        manager2.addTask("To-Do 목록 추가");

        cout << "\n현재 할 일 목록:\n";
        manager2.showTasks();

        manager2.completeTask(2);

        cout << "\n업데이트된 할 일 목록:\n";
        manager2.showTasks();

        return 0;
    }
