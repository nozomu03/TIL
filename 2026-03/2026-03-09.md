# C++
- 함수에 매개변수를 전달하는 방법
  - Call-By-Value
    - 일반 변수 전달

            #include <iostream>

            void Change4(int a) {
                a++;	
                std::cout << a << std::endl;
            }

            int main(void) {
                int a = 5;
                Change4(a);
                std::cout << a;
            }
        - 변수를 그대로 복제해서 전달
        - 원본 변수의 값이 변하지 않음
    - 포인터 변수 전달
 
            #include <iostream>

            void Change2(int* num) {
                (*num)++;
                return;
            }

            int main(void) {
                int num = 5;
                Change2(&num);
                std::cout << num;
                return 0;
            }

        - 변수의 주솟값을 복사해서 전달.
        - Call-By-Value이나 포인터가 가리키는 변수의 주소가 같기에 값이 변함
    - 배열 전달
  
            #include <iostream>

            void Change(int* num) {
                for (int i = 0; i < 5; i++) {
                    num[i]++;
                }
                return;
            }


            int main(void)
            {
                int arr[5];
                for (int i = 0; i < 5; i++) {
                    arr[i] = i;
                }
                Change(arr);
                for (int i = 0; i < 5; i++) {
                    std::cout << arr[i];
                    std::cout << " ";
                }
                return 0;
            }
        - 배열은 함수로 전달될 때 자동으로 첫 번째 인덱스의 주소로 변환
        - 포인터가 가리키는 주소에 저장된 배열은 동일하기에 값 변함
  - Call-by-Reference
    - 참조자 전달       
    
            #include <iostream>

            void Change3(int& num) {
                num++;
                return;
            }

            int main(void) {
                int num = 5;
                Change3(num);
                std::cout << num;
                return 0;
            }

        - 참조자를 전달할 시 다른 함수에서 변수의 값을 수정하면 원본 함수도 같이 변경.
- Class

        #include <iostream>
        #include <algorithm>

        class StudentSystem {
            private:
                int eng;
                int math;
                int kor;
                //멤버 변수

            public:
                double GetAverage() {
                    return (double)(eng + math + kor) / 3;
                }

                int GetMax() {
                    return std::max(std::max(eng, math), kor);
                }
                //멤버 함수

                StudentSystem(int eng, int math, int kor) {
                    this->eng = eng;
                    this->math = math;
                    this->kor = kor;
                }
                //생성자

                void SetEng(int eng) {
                    this->eng = eng;
                }

                int GetEng() const{
                    return this->eng;
                }

                void SetMath(int math) {
                    this->math = math;
                }
                int GetMath() const{
                    return this->math;
                }

                void SetKor(int kor) {
                    this->kor = kor;		
                }
                int GetKor() const{
                    return this->kor;
                }
                //getter / setter
        };

    - 접근한정자
      - public
        - 어디에서나 호출 가능
      - protected
        - 해당 클래스 + 자식 클래스에서 호출 가능
      - private
        - 해당 클래스에서만 호출 가능
    - getter / setter
      - private 필드로 선언된 멤버변수에 접근하기 위한 public 함수
      - getter
        - 멤버변수 반환
      - setter
        - 멤버변수 값 변경
        - C++에서는 은닉 + 캡슐화를 위해 setter 보다는 의미 단위의 멤버 함수 사용 권장
    - 순수 가상함수
      - 반드시 부모 클래스가 아닌 자식 클래스에서 구현되어야 하는 가상 함수
