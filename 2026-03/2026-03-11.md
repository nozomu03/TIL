# C++
## Vector
- vector는 동적 배열
  - 일반 배열(int arr[20])은 고정 크기
  - size
    - 현재 원소 개수
  - capacity
    - 확보된 메모리 공간
  - 원소 삽입
    - capacity <= size일 경우
      - 2배(1.5)배 크기의 새 메모리 할당
      - 기존 원소 복사
      - 기존 메모리 해제
      - 새 원소 추가
    - push_back()은 평균 O(1)
      - 분할 상환 분석
  - 마지막 원소 제거
    - pop()
      - O(1)
  - 중도 삽입
    - insert()
    - O(n)
  - 중도 삭제
    - erase()
    - O(n)
    - erase() 사용보다 원하는 값만 추려서 새 vector 생성 추천 
  - vector는 힙 메모리에 연속되어 할당
