# C++
## 오버로딩 / 오버라이딩
### 오버로딩
- 똑같은 이름의 함수를 여러개 정의
- 매개변수의 개수, 매개변수의 자료형으로 각각을 구분

        void MyFunc(int a, int b)
        {
            //Something...
            return;
            
        }

        void MyFunc(int a, int b, float c){
            //Something else...
            return;

        void MyFunc(int a, double b){
            //Something different...
            return;
        }
}

- 오버로딩이 불가능한 경우
  - 함수의 반환 형식만 다른 경우
    
        void MyFunc(double a){
            //Something else...
            return;
        }

        int MyFunc(char a){
            //Something different...
            return 0;
        }



  - 매개변수의 형변환으로 인해 여러 개의 함수가 호출 후보가 되는 경우    
     
        void MyFunc(double a){
            //Something else...
            return;
        }

        void MyFunc(char a){
            //Something different...
            return;
        }

        int main(void){
            MyFunc(65);
            return 0;
        }

    - int는 char와 double 양쪽으로 형변환 될 수 있음
  - 매개변수에 기본값이 주어져 여러 개의 함수가 호출 후보가 되는 경우
  
        void MyFunc(int a) {
            //Something else...
            return;
        }

        void MyFunc(int a, int b = 5) {
            //Something different...
            return;
        }


        int main(void) {
            MyFunc(67);
            return 0;
        }
    - 매개변수 b에 기본값이 주어져 두 함수 모두 호출 대상이 됨
  - 원본 함수와 오버로딩된 함수의 매개변수 간 차이가 배열과 포인터 차이 뿐일 때

        void MyFunc(int* a) {
            //Something else...            
            return;
        }

        void MyFunc(int a[]) {
            //Something different...            
            return;
        }      
    - 배열은 내부적으로 포인터로 변환되어 동일한 함수를 2번 선언한 것으로 인식
  - 컴파일러가 인자값에 따라 함수를 선택하는 원리
    - 자료형 일치 -> 값 손실이 없는 형변환(bool-int) -> 값 손실이 있는 형변환(double-int) -> 사용자 정의 형변환 
    
### 오버라이딩
- 부모 클래스에 선언된 클래스를 자식 클래스에서 재정의해서 사용
  - virtual 키워드로 선언된 함수만 가능
  - 보통 부모의 멤버함수를 오버라이딩 하는 경우 public으로 상속  

        class ParentClass {
            public:
                virtual void MyFunc() {
                    std::cout << "Parent" << std::endl;
                    return;
                }
                virtual ~ParentClass() {}
        };

        class ChildClass : public ParentClass {
            public:
                void MyFunc() override{
                    std::cout << "Child" << std::endl;
                    return;
                }	
        };
  - override 키워드
    - 부모 클래스에 정의된 가상함수와 이름이 다를 시 에러 출력
  - final 키워드
    - 함수에 붙으면 오버라이딩 금지
    - 클래스에 붙으면 상속 금지

## 템플릿

    template <typename T>
    T Add(T a, T b) {
        return a + b;
    }

- 여러 자료형에서 보편적으로 쓰이는 범용 함수의 오버로딩을 자동화
- typename T
  - T는 C++ 자료형 전반에 대응됨
  - 즉 위 함수는 a와 b의 자료형에 따라 해당 자료형을 반환하는 함수로 오버로딩 됨

- 클래스 템플릿

        #include <iostream>
        #include <vector>

        template <typename T>
        class Array {
        private:
            std::vector<T> data;
            int size;
        public:
            Array() : size(0) {}
            
            ~Array() {}

            void Add(const T& element) {
                if (this->size < 100) {
                    this->data.push_back(element);
                    this->size++;
                }
            }

            void Remove() {
                if (this->size > 0) {
                    this->data.pop_back();
                    this->size--;
                }
            }

            void Print() {
                std::cout << "Print! ";
                for (int i = 0; i < this->size; i++) {
                    std::cout << this->data[i] << " ";
                }
                std::cout << "" << std::endl;
            }
        };


        int main(void) {
            Array<int> arr;
            arr.Add(3);
            arr.Add(4);
            arr.Print();
            arr.Remove();
            arr.Print();
            return 0;
        }

  - 클래스 내의 멤버변수에 템플릿을 사용한 클래스
  - 객체 생성 시에 클래스명<원하는 자료형> 변수명

## STL
- S(tandard) T(emplate) L(ibrary)
- C++ 표준 라이브러리
- vector, map 등

    ### 컨테이너
    - 값을 담는 자료구조
    - Template으로 선언되어 있음
      - 다양한 자료형에 대응
    - iterator 제공
      - 범위 기반 반복문을 통한 순회 가능
      - begin(), end() 있음

    ### vector
    - 가변 배열
        - 초기화
          1. std::vector<자료형> 변수명 = {0}
          
          2. std::vector<자료형> 변수명(다른 벡터 변수명)

        - 2차원 벡터 선언

                std::vector<std::vector<int>> arr(세로 인덱스 크기, std::vector<int>(가로 인덱스 크기, 초기값));

        - push_back()
          - 맨 뒤에 삽입          
        - pop_back()
          - 맨 뒤에 삭제          
        - size()
          - 현재 vector의 길이 반환
        - erase()
          - 현재 vector에서 특정 위치 삭제
          - erase(시작 인덱스, 범위) 꼴로 쓸 시 범위 만큼 삭제
          - 시간 복잡도 큼

    ### map
    - <key, value> 형태의 쌍을 저장
    - key를 통해 value를 검색
    - key는 비교 가능한 자료형이여야 함
    - map<key 자료형, value 자료형>
    - insert()
      - 쌍 추가
      - insert({key, value})
      - insert 없이 []만으로 추가 가능
        - map_val[key] = value
    - find()
      - key로 iterator를 찾아줌
      - map_val.find(key)      
    - size()
      - map의 크기(쌍 개수) 반환      
    - erase()
      - map에서 특정 key 삭제
      - map_val.erase(key)
    - clear()
      - map 초기화

    ### iterator
      - begin() / rbegin()
        - 컨테이너의 첫번째 원소
      - end() / rend()
        - 컨테이너의 마지막 원소 다음     

    ### 숙제

            #include <iostream>
            #include <vector>
            #include <map>

            int main() {
                // 벡터와 맵 데이터 정의
                vector<int> vec = { 10, 20, 30, 40, 50 };
                map<string, int> mp = {
                    {"Alice", 90},
                    {"Bob", 85},
                    {"Charlie", 95}
                };

                // 문제: 아래 부분을 완성하세요

                for (auto it = vec.begin(); it < vec.end(); it++) 
                {
                    std::cout << *it << " ";        
                }
                std::cout << std::endl;
                for (auto it = vec.rbegin(); it < vec.rend(); it++) 
                {
                    std::cout << *it << " ";
                }
                std::cout << std::endl;

                for (auto it = mp.begin(); it != mp.end(); it++) 
                {
                    std::cout << it->first << " " << it->second << " ";
                }
                std::cout << std::endl;
                for (auto it = mp.rbegin(); it != mp.rend(); it++)
                {
                    std::cout << it->first << " " << it->second << " ";
                }

                return 0;
            }
