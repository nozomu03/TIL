## 동적 할당
- 과정
  - 프로그래머 원하는 만큼 메모리 요청 / 힙 메모리 관리자는 해당 크기의 연속된 메모리 반환
  - 할당된 메모리의 시작값으로 작업 수행(대여된 메모리 안의 값은 쓰레기값)
  - 메모리 반납 / 해당 메모리는 미점유 상태로 변경
  - 메모리 누수
    - 사용이 완료된 메모리가 계속 점유되어 있어 사용 가능 메모리가 줄어드는 현상
- 관련 함수
  - 할당: malloc()
    - stdlib.h 헤더파일에 정의
    - malloc(size_t size)
    - size 바이트 만큼의 메모리 반환
  - 재할당: realloc()
  - 해제(반환): free()
    - free(void* ptr)
    - free 해도 값은 남아 있음
    - free 후 null로 초기화
  - 기타
    - memset(): 초기화
    - memccpy(): A 메모리셋을 B 메모리셋에 복사
    - memcmp(): A 메모리셋과 B 메모리셋 비교
- 원본 포인터 그대로 사용 x
  - 새 변수에 할당하여 사용
  - 동적 할당된 메모리는 해당 함수에서 free 되어야 함

## Enum(열거형)
- 복수의 별명을 가진 int 변수 여러개를 묶어줌
- 여러 가지의 상수 옵션값을 표기할 때 편리.
- 예시)<br>enum EMonth{ Jan=1, Feb=2, Mar=3 };
- C++ 소스코드 내에서 enum을 변수에 할당하고 싶을 경우 (enum 변수명)::속성명
  - 예시)<br>EMonth now_mon = EMonth::Jan
  - enum 변수의 속성명을 비교하고 싶을 경우에는 Switch-Case 사용
  #### 예시)
        switch(now_mon)
        { 
            case EMonth::Jan: 
                //Do Something 
                break;
            case EMonth::Feb:
                //Do Something
                break;
        }


## 구조체
- 하나 이상의 서로 관련된 변수들을 묶어둔 사용자 정의 자료형
- struct 구조체명 변수명;
- 멤버변수 접근은 .(dot)
  - 예시)<br>struct Date date1;<br>date1.Year = 3;
- 포인터일 경우 . 대신 ->
- 초기화 방법
  - struct 구조체명 변수명 {멤버변수 값};
- 내부에는 멤버 변수 뿐 아닌 멤버 함수 역시 포함할 수 있음.

## typedef
-   이미 존재하는 자료형 / 구조체에 별명을 지어줌
    - 예시)<br> typedef unsigned long long size_t<br>typedef struct Date Date_t
  
## 구조체의 동적 할당
#### 예시)
    struct Date{
        int year;
        int month;
        int day;

        void PrintDate(){
            printf("%d:%d:%d", year, month, day);
        }
    };

    typedef struct Date Date_t;

    int main(void){
        Date_t* birthday = (Date_t*)malloc(1 * sizeof(Date_t));
        birthday->year = 2001;
        birthday->month = 3;
        birthday->day = 1;
        birthday->PrintDate();
        free(birthday);
        birthday = NULL;
        return 0;
    }
